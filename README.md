# D&D 5e / 5R 武斗构筑工坊

线上地址：https://wilder.asia/dnd-calculator/

玩家选择 **5e（2014）或 5R（2024）→ 职业 → 子职 → 1—10 级 → 武器与战斗方式 → 本轮能力与环境**，再点击计算。默认不展示预先生成的职业排名或伤害表。

## 范围与数据来源

- 两版各 12 个职业：野蛮人、战士、武僧、圣武士、游侠、游荡者，以及吟游诗人、魔契师、剑咏法师、牧师、德鲁伊、奇械师。
- 5R：62 个子职入口，含六大武斗职业 2024 PHB 全部 24 个子职；其他武器流与新版扩展分来源收录。
- 5e：98 个子职入口，使用 2014 职业框架与旧版正式扩展；不混入 2024 重写子职。
- 法师仅收录武器专精的剑咏者；不收录 UA、自制和其他纯施法法师子职。单职业 1—10 级，不处理兼职。
- 数据来源：[Kiwee 职业页](https://5e.kiwee.top/classes.html)及该站 `data/class/`、`data/items-base.json`、`data/books.json`，获取于 2026-11-03。数据文件只包含名称、等级和数值事实，不打包规则全文。
- 两版资料、子职解锁等级和武器表分别保存在 `src/data/classes-2014.json` 与 `classes-2024.json`；`provenance.json` 记录来源与输入摘要。

**子职入口不等于所有能力均已自动化。** 基础成长与已提供选项自动计算；防御、治疗、复杂施法、条件控制、伙伴/野兽卡等由玩家配置。界面会展示当前等级规则索引、已实现选项、未实现范围与配置提示。伙伴和形态使用独立命中与伤害数据，不继承角色武器参数。

## 玩家配置

- 主/副属性数值、实际攻击属性、熟练、武器、附魔、战斗风格、附赠动作、反应攻击。
- 按版本和等级显示可选特性；切换版本清空不兼容的特性与动作选择，保存方案保留各自版本。
- 目标 AC、外部优势/劣势、受伤、首轮与尚未行动、2014 受惊，以及 13 种伤害的抗性/免疫/易伤。
- 自定义每击附伤、每回合一次附伤、已确认直接伤害，分别指定类型及重击翻倍。
- 最多保存 4 套方案，用同一目标环境比较；配置保存在浏览器本地。结果保留上次计算快照，改动后提示重新计算。

## 计算口径

- 总命中由主属性调整值、熟练、附魔与调整组成。属性不会随升级自动加点；请自行计入 ASI 与半专长。
- 攻击序列分别处理攻击动作、动作如潮、迅击、附赠攻击、第二目标和回合外反应攻击；不会把所有攻击粗略乘以同一伤害。
- 每回合一次附伤在首次符合条件的命中使用，不等待重击；回合外仅偷袭可再触发。
- 5R 巨武器大师为攻击动作重型命中加熟练值；5e 为 -5/+10。5R 至圣斩每轮一次并占附赠动作；5e 每次近战武器命中均可消耗资源。两版武僧、狂怒、巨武器战斗、猎人印记与幽域追踪者等分别处理。
- 2024 武器精通自动实现擦掠、侵扰和迅击；失衡的豁免与横扫等复杂条件需要玩家另行设置。
- 戏法替换仅按轰雷剑类武器命中型戏法估算，不包含移动追伤；其他戏法请手动配置。未自动模拟命中后资源决策、逐次取整、专注中断和敌人行动。
- 资源充足、前置条件与本轮触发由玩家确认。伙伴指挥的具体动作成本需根据所用数据卡核对；伙伴的附赠动作模式不自动等同于 2014 PHB 驯兽师的指挥规则。
- 原来的“自由计算 / 法术豁免”保留独立参数与页面上的计算口径说明；不自动继承工坊规则版本。

## 本地开发与验证

使用满足 Vite 8 要求的 Node.js 22.12+。

```sh
npm ci
npm run dev
npm test
npm run build
```

43 项测试覆盖 620 个 5R 等级配置、980 个 5e 等级配置，以及版别差异、动作经济、首次命中、侵扰、擦掠、双持、豁免与损坏存储。遍历测试验证配置可计算，不能代替每条规则的人工审计。

## 部署

构建输出 `dist/`，基础路径 `/dnd-calculator/`。只上传构建文件，由已有 Nginx 和 HTTPS 提供；没有 Node 常驻进程。

- 当前链接：`/var/www/dnd-calculator/current`
- 版本目录：`/var/www/dnd-calculator/releases/<版本>/`
- Nginx 路由：`/etc/nginx/dnd-calculator.locations`
- 部署清单：`/var/www/dnd-calculator/deployment.json`

更新先测试和构建，上传完整版本并校验文件摘要后原子切换 current。旧版本保留供回滚。GitHub 更新不自动发布。
